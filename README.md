# My-Portfolio

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)]([https://your-vercel-link.vercel.app](https://my-portfolio-livid-omega-95.vercel.app/))

This is the source code for my personal developer portfolio website. It serves as a digital resume to showcase my skills, projects, and academic background as an Information Technology student at the University of Cape Coast.

Built With
HTML5 & CSS3
JavaScript (Responsive Hamburger Menu)
Remix Icon (For icons)
Google Fonts (Oswald typography)

Features
Fully Responsive: Optimized for both desktop and mobile devices.
Frosted Glass Navbar: A modern, translucent navigation bar with a blur effect.
Animated Skills Grid: Hover effects on skill tags and project cards.
Contact Form: Functional design with modern input styling.
Lightweight & Fast: No heavy frameworks used, built purely with vanilla web technologies.

File Structure

index.html - Main layout file.
portfolio.css - All custom styling.
script.js` - Mobile navigation logic.
